Notes on how fonts will be used

Viaoda Libre will be used for headings (h1).

  • Size, 28 to 36px.
  • The font will be used in its intended form and it does not include multiple style options.

Viaoda Libre will also be used for subheadings (h2).

  • Size, 22px.
  • The font will be used in its intended form and it does not include multiple style options.

Raleway will be used for the main text (p and l tags etc.).

  • Size, 16 to 20px.
  • Regular (400)
